# Skyfall

Original offline survival game built with React, Three.js, Vite and Capacitor.

## Build the APK

```bash
npm install
npx cap add android
npm run build:apk
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`

The Android SDK, Java, and Gradle are required locally. This repository contains the complete source and build configuration; the APK is generated by the command above.
